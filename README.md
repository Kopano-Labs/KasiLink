## What Is This

KasiLink connects township talent to opportunities. KC AI chatbot active. Clerk authentication. Cassey's teacher lane governs quality.

An **Adaptive PWA** — not just a job board. It adapts across **6 dimensions** to serve users on cheap Android phones with intermittent connectivity.

## Adaptive PWA — 6 Dimensions

| # | Dimension | KasiLink Implementation |
|---|-----------|------------------------|
| 1 | **Connectivity** | Offline-first job cache · Store-and-forward applications |
| 2 | **Role** | Job seeker · Employer · Community leader · Admin |
| 3 | **Urgency** | Standard browse → urgent hiring → community alert |
| 4 | **Device** | Budget Android priority · Data-light payloads |
| 5 | **Trust** | Verified employers · Rated gigs · Scam protection |
| 6 | **Local Context** | Township · Ward · Language · Skill type · Transport radius |
